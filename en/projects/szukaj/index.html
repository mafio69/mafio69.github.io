02

Problem → solution

Problem

An AI agent that needs to search the web usually gets it through an external API: paid, rate-limited, with no control over where the queries go.

Solution

A private SearXNG metasearch engine with an MCP server. Agents and the browser use the same engine. When SearXNG finds nothing, Perplexity can answer as a fallback — with a daily limit.

03

Three engineering decisions

  1. 1
    An explicit response statusThe server returns ok, empty or error. The client (virral-agents) can tell “no results” from a failure instead of showing an error for an empty list.
  2. 2
    Search doesn't block the serverThe logic is asynchronous with a connection pool. One slow query doesn't freeze the UI or other agents.
  3. 3
    Safe defaultsPort bound to 127.0.0.1 only, DNS rebinding protection, an optional Bearer token for /mcp, a container without root privileges.
