02

Problem → solution

Problem

A home with a voice assistant needed one voice for scripts, timers and people — one that keeps working when the network or a cloud service doesn't.

Solution

A small dependency-free C++17 engine that speaks the Wyoming protocol itself to Piper (text → speech) and faster-whisper (speech → text), plus a calm Qt window. Saved messages play even with the speech server down.

Three engineering decisions

  1. 1
    Zero dependencies at the coreThe engine needs only a C++17 compiler: its own JSON, WAV and Wyoming client. Fewer things to break on a system update.
  2. 2
    One command for everyoneResults on stdout, diagnostics on stderr, documented exit codes. A script, a cron job and a person at the keyboard use the same interface.
  3. 3
    Never a raw errorThe user sees one plain sentence: what happened and what to do. Technical details go to a log file.
